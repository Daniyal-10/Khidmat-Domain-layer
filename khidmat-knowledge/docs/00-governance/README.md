# 00-governance

## Purpose
Governance & Foundations. Contains project identity, constitution, and universal glossary.

## Scope
- **In Scope**: Project Overview, Constitution, Foundation, Vision, Glossary.
- **Out of Scope**: Implementation details, Methodology, Domain models, placeholder documents.

## Canonical Documents
- `PROJECT_STATUS.md` — Governance dashboard showing current repository state and active phase.
- `KHIDMAT_FOUNDATION_PIPELINE.md` — Canonical roadmap defining what constitutes the complete Khidmat Foundation prior to Ontology Design.
- `PROJECT_OVERVIEW.md` (v1.0, frozen) — sole conceptual authority.
- `CONSTITUTION.md` (v1.0, frozen) — sole governance authority.
- `GLOSSARY.md` (v1.0) — fully synchronized and normative.
- `GOVERNANCE_COMPLETION_REPORT.md` — Certification of foundation completeness.

*(Note: `PHILOSOPHY.md` and `PRINCIPLES.md` were deprecated and removed to ensure strict uniqueness of governance responsibility without duplication).*
