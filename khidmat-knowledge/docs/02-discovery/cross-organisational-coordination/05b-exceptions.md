# 15. Exceptions

- **Emergency Life-Saving Override:** Sharing critical medical context with an external surgical NGO without documented consent if the beneficiary is unconscious. This exception is strictly governed by necessity, proportionality, collection of the minimum information required, transparency to the person as soon as possible, and continued human accountability.
- **Mandatory Reporting Override:** Legally mandated sharing of safeguarding abuse context with a state authority, bypassing the consent requirement.
- **Trust Suspension:** Immediately cutting off all context sharing with a Partner Organisation if they suffer a severe data breach or safeguarding scandal.
