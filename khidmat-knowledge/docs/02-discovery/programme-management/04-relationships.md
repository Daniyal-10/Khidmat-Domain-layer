# Business Relationships

- A **Programme** targets a **Target Population**.
- A **Programme** contains an **Intervention Catalogue**.
- An **Intervention Catalogue** defines multiple **Intervention Offerings**.
- A **Grant** funds a **Programme**.
- A **Programme** spans a **Geographic Area**.
- An **Eligibility Rule** governs an **Intervention Offering**.
- A **Budget** constrains an **Intervention Offering**.
- A **Sector** categorizes a **Programme**.
- An **Indicator** measures a **Programme**'s success.
- **Priority** influences **Allocation**.
