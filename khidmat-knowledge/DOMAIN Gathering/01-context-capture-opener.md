# Context-Capture Opener — GT Session with Affan

**Purpose.** Per Framework Rule R-5, no answer Affan gives can be correctly interpreted without
knowing whose ground reality it describes. This is asked **once at the start**, then
**re-confirmed per topic** if Affan's experience spans more than one organisation, programme, or
geography. Do not skip this because it feels like small talk — GT-P2 (Context), GT-PL2, and
CCR-1 (altitude qualification) are only meaningful once this is on record.

Record the answers verbatim in a running "Session Context Log" — do not fold them into
individual GT records; instead, reference the relevant Session Context Log entry from each
GT record's "Humanitarian context" field.

---

## A. Opening questions (ask before any ontology-related question)

1. **Organisation type.** What kind of organisation(s) have you worked with — NGO, INGO,
   community-based organisation, government body, UN agency, other? If more than one, which
   one(s) will your answers today mostly draw from?
2. **Mandate / sector.** What sector(s) — protection, health, shelter, livelihoods, food
   security, multi-sector, other?
3. **Role and tenure.** What has your role actually been (case management, MEAL, programme
   coordination, field verification, other)? How long, and is this current or past experience?
4. **Geography.** Which country/countries and region(s)? Urban, rural, or both?
5. **Scale of operation.** Roughly how many households/cases per programme cycle — small
   localized response, or large multi-programme operation?
6. **Setting type.** Acute emergency response, protracted/chronic caseload, or both? Displacement
   context, host-community context, or both?
7. **Multiple contexts flag.** Have you worked across more than one organisation, country, or
   programme type in ways where the answer to a question might genuinely differ depending on
   which one you're drawing from? If yes — flag this now so we ask "which context?" per topic.

## B. Per-topic re-confirmation (use if #7 above is "yes")

Before each major section (Facets, Entities, Relationships, Constraints, States, Events,
Cognition, Coordination), ask:

> "For this next set of questions, which organisation/programme/geography are you describing?"

Log the answer as `Context tag: [short label]` and carry that tag into every GT record produced
from that section, in the **Humanitarian context** field — replacing the current placeholder
value "Unspecified" that appears throughout the existing synthetic records.

## C. What NOT to do here

- Do not explain the ontology's structure or terminology while gathering context — this section
  is pure fact-finding about Affan, not about Khidmat.
- Do not skip re-confirmation between sections just because the first answer seemed to cover
  everything — GT-PL2's whole finding depends on being able to show the *same* condition meaning
  different things in *different* contexts, which requires knowing the context changed.
